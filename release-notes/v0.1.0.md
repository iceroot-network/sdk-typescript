The first release. The interfaces below changed shortly before it; code written against earlier development builds needs these changes.

- **No fee from the node's statistics.** `Draft.build(chain, request, facts)` takes no fee statistics any more, the builders of `net.build` never read `/node/fees`, and `FeeSource` is `"floor"` or `"explicit"` (the `"node-statistics"` source is gone). `net.fees.statistics()` stays, for display. A serialized draft whose fee source names anything other than `"floor"` reads as `"explicit"`.
- **No floor without an enabled fee table.** Where the milestone in force has no enabled dynamic fee table, the node's pool applies settings of its own, so there is no floor: `rules.fees.floorAvailable` is `false` (it now says whether the floor is in force at that height), `draft.summary.fee.floor` is absent, and fee `"minimum"` and `{ multiplierBasisPoints }` throw `FeeUnavailable`. Such a network needs an exact `bigint` fee. A draft never carries a zero fee labelled as the floor.
- **Headers for a relay behind a proxy.** `connect(profile, { headers })` sends extra headers with every request, for a relay that asks for a token. The Rust SDK of the same version adds the same to its HTTP client (`HttpOptions::headers`), so a Rust backend reaches the same relay.
- **`net.watch`.** Stopping a watch, by the function it returns or by its `signal`, now also removes its listener from that signal. The documentation states its limits: one `block` event per poll for the latest block, and at most 50 new transactions per poll for the watched address.
