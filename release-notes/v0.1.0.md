Version 0.1.0 is the initial pre-release package. It is not yet published to npm, and no GitHub release is available yet. The API may change before 1.0.

### Package contents

- The SDK's Rust core compiled to WebAssembly, with a typed TypeScript and JavaScript wrapper. Browser, Node and classic-script builds share the same module.
- Recovery phrases, hardened account derivation, devnet legacy passphrase imports, addresses and exact amounts in base units.
- A typed node client, network identity checks, transaction builders, review summaries, draft serialization, signing, submission and polling for inclusion.
- Transfers, votes, burns, second keys, validator registration, resignation and resignation revocation on the classical devnet.
- Message signatures, checked sign-in challenges, and account links and revocations.
- Separate vote-selection, encrypted-keystore and Solar-address ownership-proof entry points.
- A Tauri entry backed by sdk-rust's native plugin, with keys, signing, keystores and node requests in Rust. Calls that compute return promises.
- Vite and React and native Tauri examples.

### Hosts and networks

The package loads in Node 22, browsers, Next.js, Vite and React, Tauri webviews and Manifest V3 extensions. WebAssembly pages require `'wasm-unsafe-eval'` in their content security policy. The native Tauri plugin loads no WebAssembly.

Only `profiles.devnet` and classical Solar-compatible formats are supported today. Post-quantum formats, IceRoot formats and public testnet or mainnet profiles are not supported by this package yet. Check capabilities before offering an operation; finality is not available on the classical devnet.

### Size and installation

The shared WebAssembly module has a size budget of 425 KiB gzipped. The release script records the actual module size and source revisions in the generated release notes.

Build from source using the development guide until the first release. That release will attach the built package tarball, the standalone WebAssembly module, its embedded-byte script and `SHA256SUMS`.
